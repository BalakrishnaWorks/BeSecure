
# BeSecure Privacy Policy

BeSecure is a local desktop website security assessment
prototype.

## Data collection
BeSecure is designed not to require an account, cloud
storage, or telemetry.

## Network activity
When a user starts a scan, BeSecure makes network
requests to the website entered by that user.
The destination website may receive the user's network
address and normal request metadata.

## Local data
Scan history is not intended to be uploaded automatically.
Users should review any report before saving or sharing it.

## Limitations
This policy describes the intended design. Users should
review the source code and release behavior before relying
on these statements.

## Security
Only scan websites that you own or have explicit permission
to assess. BeSecure is not a guarantee of website security.
